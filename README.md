# DSES 3D Tank

Storage tank inspection and repair planning in 3D, for Windows.

Model a vertical storage tank from a few dimensions, mark repairs on the shell, floor, roof and fittings, record thickness readings against API 653, and produce inspection report packs, work packs and shutdown schedules.

## Download

Get the latest installer from the [Releases](../../releases/latest) page: `DSES-3D-Tank-Setup-<version>.exe`.

The installer is per-user and needs no administrator rights. Once installed, the app checks this page for new versions and offers to update itself.

## What's in it

- To-scale 3D tank model: shell strakes, bottom and annular plates, nozzles, wind girder, spiral staircase, platforms and five roof types
- Repair marking with status tracking, photos and measurements
- Thickness evaluation (API 653 minimum thickness, corrosion rate, remaining life)
- Settlement survey check (API 653 Annex B), MFL floor scan import and an NDT log
- Inspection report pack PDF with cover, document control, sign-offs and recommendations
- Work pack: ITP hold points, approvals, cost estimate and Gantt shutdown schedule
- Presentation mode with MP4 turntable video
- `.dses3d` project files, undo and redo, autosave and automatic backups

## Release files

Each release carries the Windows installer and `latest.yml` (version, size and SHA-512 checksum), which the app uses to verify downloads before installing.
